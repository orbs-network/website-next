# Additional chain marks

Existing chain marks reuse `public/marketing/agentic/chains/`; these five complete Sara's thirteen-chain handoff. The vectors retain source geometry with dark ink for the white logo containers. Brand marks remain subject to their owners' trademark rights.

- **Sei:** [official site](https://www.sei.io/), [network lockup](https://cdn.sei.io/web-v2/sei-network-logo.svg). Crop the viewBox to the 24px symbol; normalise ink to `#121214`.
- **Flare:** [official site mark](https://flare.network/api/media/file/Flare.svg). Retain geometry; normalise ink to `#121214`.
- **Katana:** [official site mark](https://katana.network/images/logomark.svg). Retain geometry; use dark ink on white rather than the site's fluorescent yellow.
- **Monad:** extract the inline `Monad Logomark` SVG from the [official homepage](https://www.monad.xyz/). Remove page-specific visibility classes; retain the official symbol colour.
- **Berachain:** the 192px [official documentation icon](https://docs.berachain.com/mintlify-assets/_mintlify/favicons/berachain-422fce37/GhFtmoYvIj_GkgM5/_generated/favicon/android-chrome-192x192.png), linked by [the documentation homepage](https://docs.berachain.com/). Retain the original raster and colours.
