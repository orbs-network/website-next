# Monochrome chain marks

These transparent vectors retain the source brand geometry. Colour fills are
normalised to black; the page inverts them in dark mode.

- Ethereum and BNB Chain: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), CC0.
- Avalanche: [Ava Labs black logomark](https://github.com/ava-labs/avalanche-docs/blob/HEAD/public/common-images/Avalanche_Logomark_Black.svg).
- Arbitrum: [Offchain Labs logo](https://github.com/OffchainLabs/arbitrum-docs/blob/HEAD/static/img/logo.svg); retain the shield outline and letter paths, omit the coloured backing.
- Polygon: [Polygon documentation icon](https://github.com/0xPolygon/polygon-docs-old/blob/HEAD/docs/img/home/polygon-icon.svg); retain the linked polygon path, omit the coloured backing and crop the viewBox to the mark.
- Base: [Base brand kit symbol](https://github.com/base/brand-kit/blob/14eef1393ddc00c6b388565234a79e84be5b2c04/logo/symbol/Base_Symbol_Black.svg); use the existing circular identity rather than replacing it with the newer square identity.
- Linea: [Consensys Linea mark](https://github.com/Consensys/doc.linea/blob/HEAD/static/img/Linea_mark_light.svg).
- Sonic: [Sonic Labs logo](https://www.soniclabs.com/sonic-logo.svg); retain the symbol paths, omit the wordmark and duplicate gradient layers.

Brand marks remain subject to their respective owners' trademark rights.
